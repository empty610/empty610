# Texture provenance

`earth_atmos_2048.jpg` is the Earth texture from the official Three.js `r160`
tag:

`examples/textures/planets/earth_atmos_2048.jpg`

Verification values:

```text

SHA-256:        2faa400d1eade3bc44caf6750d1b772bd9bbb6d87362c02bc7c3304e78fa0a9d
```

`earth_atmos_2048.data.js` is a generated data-URL copy of the same JPEG. It is
loaded only for direct `file://` previews because browsers do not allow a local
JPEG with an opaque file origin to be uploaded to WebGL. Deployed HTTP(S) pages
continue to load the smaller JPEG file. Its SHA-256 is:

